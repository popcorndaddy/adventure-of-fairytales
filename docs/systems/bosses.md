# Bosses
Search keys: withered sentinel, ancient gatekeeper, geckolib, blender, animation

- Withered Sentinel: `overrides/kubejs/startup_scripts/bosses/withered_sentinel.js`, model and
  animations under `overrides/kubejs/assets/kubejs/`; Blender sources in `dev/withered_sentinel/`;
  the GeckoLib bridge in `tools/blender-geckolib/`.
- Ancient Gatekeeper: Forge mod in `gatekeeper-mod/` (GeckoLib 4.8.5), art and Blender scripts in
  `gatekeeper-art/`; guards the End portal (`endrem:ancient_portal_frame`).
- GeckoLib axes: file x negated; rotations negate x and y; Blender bones use XZY Euler.
