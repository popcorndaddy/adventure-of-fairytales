# The modpack
Search keys: manifest, overrides, curseforge zip, pack build

- `manifest.json` holds CurseForge project/file IDs; `overrides/` is copied over the mods on install.
- Build: zip `manifest.json`, `modlist.html`, `overrides/` at the zip root with forward slashes.
- Branches: `unpack-pack` (the unpacked pack, PR #1), `feature/gatekeeper-boss` (Gatekeeper mod +
  pack zip 1.1.0, PR #2), `feature/sentinel-animations` (Sentinel animation overhaul).
- Local instance: `%USERPROFILE%\curseforge\minecraft\Instances\Adventures of Fairytale`.

See also: docs/systems/server.md, docs/systems/bosses.md
